===============================================================
         TAKAFUL — Guide d'installation XAMPP
===============================================================

ÉTAPES D'INSTALLATION :
========================

1. INSTALLER XAMPP
   - Téléchargez XAMPP depuis : https://www.apachefriends.org/fr/index.html
   - Installez-le (chemin par défaut : C:\xampp)
   - Lancez XAMPP Control Panel
   - Démarrez Apache et MySQL (cliquez "Start" pour les deux)

2. COPIER LE PROJET
   - Copiez le dossier "takaful-php" complet dans :
       C:\xampp\htdocs\
   - Renommez-le en "takaful" (optionnel mais recommandé)
   - Résultat : C:\xampp\htdocs\takaful\

3. CRÉER LA BASE DE DONNÉES
   a) Ouvrez votre navigateur et allez sur : http://localhost/phpmyadmin
   b) Cliquez sur "Nouvelle base de données" (ou "SQL")
   c) Cliquez sur l'onglet "Importer"
   d) Cliquez "Choisir un fichier" → sélectionnez "takaful.sql"
   e) Cliquez "Exécuter"
   
   OU via l'onglet SQL, copiez-collez le contenu de takaful.sql

4. ACCÉDER AU SITE
   Ouvrez : http://localhost/takaful/index.php

✅ MEMBRE D'ASSOCIATION

✅ ADMINISTRATEUR SYSTÈME
   - Tableau de bord global avec statistiques

===============================================================
EN CAS DE PROBLÈME :
===============================================================

• "Accès refusé" base de données :
  → Vérifiez que MySQL est démarré dans XAMPP
  → Vérifiez les identifiants dans config/db.php
    (par défaut : root / pas de mot de passe)

• Page blanche :
  → Activez l'affichage des erreurs PHP dans XAMPP
  → Vérifiez que la base "takaful" existe dans phpMyAdmin

• Problème de chemins :
  → Votre projet DOIT être dans htdocs/takaful/
  → Accédez via http://localhost/takaful/ et non http://localhost/
